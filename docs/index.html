Quick guide

Welcome to the table

  • The host clicks the table badge to create an offer code and sends it to a player.
  • The player creates an answer code and sends that back. No server or account is involved.
  • Import a Tabletop Simulator save or saved-object JSON file.
  • Click the draw pile to add a private card to your hand.
  • Double-click a hand card to play it face-up in the center.
  • Drag table cards to arrange them. Double-click to flip. Right-click to take one.
